Case Study — Employer Work

Unified Volunteers Platform

Employer work — summary only. Code and product are employer-owned; nothing proprietary is shown here.

Context

The Unified Volunteers Platform is the UN Volunteers programme's system for volunteer registration, candidate profiles, host-organisation management, opportunity publishing, assignments and recruitment workflows — serving a global audience.

My Role

Full-stack software engineer at NTT DATA, shipping features across a React/TypeScript frontend and a .NET microservices backend: role-based access, multilingual interfaces, document handling, search, notifications, and integrations with external UNV systems.

Stack & Patterns

.NET microservices on Azure and Kubernetes, with CQRS and Saga orchestration and event-driven communication over Service Bus. AI services built by a dedicated team are consumed through APIs where workflows need them.

Outcomes

Production features delivered to a live global platform. One measured result: a recruiter data export that took a colleague 2+ hours over ~400 records now runs in under 30 minutes after I rebuilt it as an automated batch process.
